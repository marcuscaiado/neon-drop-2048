## ✨ Features & Highlights

- 🎱 **Circle Rigid-Body Physics**: Balls roll, bounce, and displace one another dynamically inside the jar.
- 💥 **Satisfying Pop Chain Reactions**: Matching adjacent numbers instantly merge into higher tier spheres (2 ➔ 4 ➔ 8 ➔ 16 ➔ ... ➔ 2048!).
- 🎯 **Target Line Trajectory**: Aim guide shows exact drop coordinates.
- 🔊 **Soothing ASMR Audio**: Procedural marimba notes and harmonic chords scaling up with higher merge numbers.
- 🏆 **Arcade Leaderboard Sync**: Compete globally for the highest jar merge record.
